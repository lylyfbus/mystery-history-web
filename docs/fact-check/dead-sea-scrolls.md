## Title, description, image

Title says "2,000-Year-Old Texts That Rewrote Biblical History"; the scrolls mostly confirm the Bible text and add context, so "rewrote" is strong. Suggested fix: "Reshaped what we know about Biblical history". Description and image alt not checked beyond this.
