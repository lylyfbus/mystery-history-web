## Title, description, image

Title says the hikers "Died in Ways That Still Defy Explanation" and the description says injuries "no one can explain". Russia named an avalanche in 2020 and a 2021 study modelled the injuries, so these are too strong. Suggested fix: "...Died in Ways That Are Still Argued About" and "Their bodies were found with injuries that experts still argue about." Image alt text was not checked.
