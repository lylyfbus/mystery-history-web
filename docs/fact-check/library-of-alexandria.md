## Title, description, image

Meta description says the library was "destroyed" as if by one act, and asks "Who did it?". No single destruction is documented. The title says "The Greatest Collection of Knowledge" as fact. Suggested fix for description: "Founded in the 3rd century BCE, the Library of Alexandria was famous across the ancient world. It faded over centuries. What was lost?"
